# Phase 3: Design Synthesis (July 23, 2026)

**Live preview (public, opens in any browser, no login):**

https://thara-messeroux.github.io/ngn-category-landing-prototypes/phase-3-synthesis/

Status: frozen. This is the exact design shown to stakeholders on July 23, 2026. We do not change it after the presentation, so it stays as the record of what was approved. New work continues in phase-4-mobile-refinement.

## What this is

The first combined direction. It uses Zach's composite layout (08-composite-v3.html) as the base and adds Thara's Option 2 and 3 pieces, following the team's decision to bring both explorations into one design.

Added from Thara's work:
- The Most Read rail card
- The all-newsletters chooser (Daily, Weekend, Parents, Research, Faculty and Staff) with real cadences
- Tighter list styling

Design system details:
- NGN section bars (uppercase Lato labels with the red accent rule)
- Square images, no rounded corners
- No condensed headline type, and kickers used sparingly
- Clickable subtopics. Each one opens an in-page collection with curated stories, a "More University News" archive grid, a Load More button, and a link to the full tag archive.

## Feedback from the July 23 presentation

- The team said the user experience improved.
- They asked for a strong mobile experience and a few more refinements for the next meeting. Those are tracked in phase-4-mobile-refinement.
- They also liked a header pattern Zach built on his own: a sticky bar with the title on the left and the topics on the right. See 10-composite-v5.html and the note in the main README.
